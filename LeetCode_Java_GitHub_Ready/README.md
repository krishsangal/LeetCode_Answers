# Java DSA & LeetCode Practice

A GitHub-ready collection of Java solutions from my DSA practice.  
Every LeetCode file includes the **question number and problem title in the filename** so problems are easy to identify.

## Repository Structure

```text
LeetCode/                      # Problems from my practice list
Java_Basics_GFG_HackerRank/    # Java basics, OOP, exceptions, collections, file handling
Extra_Practice/                # Additional recommended LeetCode problems
```

## Notes

- LeetCode supplies helper classes such as `ListNode`, `TreeNode`, and `Node` for relevant problems.
- Design problems use the class name required by LeetCode (for example `ParkingSystem`, `TicTacToe`, `SnakeGame`, and `Excel`).
- The code is intended as study material and can be improved with alternative approaches and explanations over time.
